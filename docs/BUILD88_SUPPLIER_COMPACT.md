# Build 88 - Compact Supplier Priorities

UI-only change approved for Tasks Assistant.

- Cycle Focus keeps its title and four stats, but the explanatory paragraph moves into an information control beside the Cycle Focus label.
- Supplier priority task cards use two visual rows: title/action on the first row; targeted products, estimated score and Supplier Closer badge on the second row.
- Supplier Closer remains the same existing badge label/state; only its placement changes.
- Card padding and list gaps are reduced so more supplier priorities are visible without scrolling.
- Recovery, Review, Master Data, scoring, supplier ranking, badges, completion rules and Supabase are unchanged.
